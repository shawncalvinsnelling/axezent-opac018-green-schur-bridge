# Literature Comparison

This document is a reviewer aid. It summarizes what should be compared against the surrounding literature before any final claim is made.

## Zaslavsky signed graphs

Relevant role: signed-graph switching and balanced/unbalanced component structure.

Reviewer task: confirm that the component decomposition used in the manuscript is exactly the one licensed by the signed-graph theorem being cited, and that the root-system translation introduces no extra cases.

## Cellini-Marietti style root-polytope geometry

Relevant role: root polytopes, convex-hull containment, and transfer from component geometry to polytope gauges.

Reviewer task: verify that each gauge identity and facet/dual-polytope reduction is being used under the hypotheses of the cited result.

## Hopkins-Postnikov style root-system combinatorics

Relevant role: comparison point for root-system chip-firing, root-polytopal formulas, and exact rational invariants.

Reviewer task: determine whether the formulas in this package are new, reformulations of known formulas, or consequences of existing results under specialized hypotheses.

## Claimed novelty boundary

The repository should be read as proposing a compact solution-candidate route and exact-audit packaging for the OPAC-018 projection-bound problem under the stated scope. It should not be read as claiming independent literature priority or journal acceptance before external expert review.

## What reviewers should report

A useful external review should identify:

1. whether the target theorem is already known;
2. whether each dependency is correctly cited;
3. whether any cited theorem has extra hypotheses missing from this manuscript;
4. whether the Type B and Type D reductions introduce hidden cases;
5. whether exceptional families remain outside scope.
