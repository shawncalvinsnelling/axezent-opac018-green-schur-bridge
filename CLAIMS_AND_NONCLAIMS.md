# Claims and Nonclaims

## Claimed by this package

This repository presents a **solution-candidate research package** for OPAC-018. It includes:

- documented rational formulas and envelope checks for representative classical-family block configurations;
- exact-arithmetic Python consistency checks;
- negative-control tests;
- reviewer-facing assumptions, examples, dependency maps, and open audit items;
- deterministic JSON receipts and a SHA-256 manifest.

## Not claimed

This repository does not claim:

- independent referee acceptance;
- journal acceptance;
- a complete peer-reviewed theorem;
- resolution of exceptional-family cases unless explicitly marked;
- resolution of unrelated famous problems;
- floating-point numerical proof;
- a replacement for mathematical referee review.

## Safe public label

**SOLUTION-CANDIDATE / EXTERNAL REVIEW PENDING**

## Software truth boundary

The software reports whether the encoded formulas, examples, and boundary checks pass over exact rational arithmetic. The software does not, by itself, prove that the mathematical reductions encoded in those formulas are valid in the full external-theorem sense.
